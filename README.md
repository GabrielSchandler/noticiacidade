# Notícias Cidade

Layout de um portal de notícias com várias páginas, feito com HTML e CSS como projeto de estudo.
Multi-page news portal layout built with HTML and CSS as a learning project.

[🇧🇷 Português](#-português) · [🇺🇸 English](#-english)

---

## 🇧🇷 Português

### Sobre o projeto

Modelo de site de notícias com uma página inicial de destaques e páginas por editoria: **Brasil**, **Internacional**, **Economia**, **Saúde**, **Ciência** e **Fotos**. Os textos são de preenchimento (lorem ipsum). O foco do projeto é a montagem de um layout de portal: menu, destaque principal e grade de notícias.

### Tecnologias

- HTML5
- CSS3

### Como usar

Baixe o repositório e abra o `index.html` no navegador.

### Estrutura

```
index.html                              página inicial com os destaques
brasil.html, internacional.html,
economia.html, saude.html,
ciencia.html, fotos.html                páginas de cada editoria
css/estilo.css                          estilos
imagens/                                imagens das notícias
```
